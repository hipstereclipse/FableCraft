# Next original-TLC door candidate: Greatwood Caves / Butterfly House

Read-only audit, 2026-09-13. **Recommended next canonical pairing: Greatwood Caves -> The Butterfly House -> Cutlass Bluetane.** This is the strongest retained evidence package after Library Arcanum and Arboretum: an explicit nonconsumptive challenge, a named singular reward, and paired original source/interior pictures. This ranking reflects evidence and bounded challenge scope, not a claim that its missing source geometry is already implemented.

## Primary evidence inspected

The retained 2005 *Fable: The Lost Chapters* Prima guide PDF is `tmp/conformance/reference-arcanum/prima-tlc-guide.pdf`, originally downloaded from:
https://www.ogxbox.co.uk/media/com_eshop/attachments/Fable_The_Lost_Chapters_Strategy_Guide_Book.pdf

- **PDF page 174 / printed page 173:** the Greatwood Caves Demon Door entry specifies an active combat multiplier of at least 14 when speaking to the door. Its source screenshot shows a pointed stone face frame beside trees and a torch; the paired interior screenshot visibly labels the destination **The Butterflyhouse**. The reward column names the cleaver, with a spelling error in this one column. The small dark interior picture has a chest ahead, a tree trunk at right and a brightly shielded player obscuring the centre; it does not establish the room's perimeter, size, route widths or lighting.
- **PDF page 47 / printed page 46:** the walkthrough independently specifies the same threshold and correctly spells **Cutlass Bluetane**, describing it as a Legendary cleaver. The original map separates Greatwood Caves from **Hobbe Cave Entrance**, Greatwood Cullis Gate and Darkwood Entrance. Therefore the existing Hobbe Cave dungeon must not simply be relabelled as this source.
- **PDF page 110 / printed page 109**, retained text inspected: the weapon table also places Cutlass Bluetane inside the Greatwood Caves door. No Fable damage/value numbers are adopted as Minecraft balancing by this audit.
- `docs/DEMON_DOOR_DESIGN.md` independently retains the area-item-FAQ pairing/reward attribution; `architecture.md:143` and `FableCraft_BuildSpec_FullWorld.md:229` identify the Butterfly House. Their spaced name differs from the guide's onscreen concatenation; record that display-name distinction rather than silently claiming exact original typography.

## Concrete next implementation boundary

1. **Source is missing.** `scripts/gen_structures.py` owns `hobbe_cave`, `rose_cottage` and `knothole_glade`, but no Greatwood Caves source builder. `main.js:STRUCTS` likewise has `fc:hobbe_cave`, not a Greatwood Caves source/face. First author and independently survey a bounded new-source clearing/rock face with supported front approach, clear throat and safe return fallback. Enrol only newly generated sources with immutable source/region identity and placement receipts; never rebuild saved caves or adopt an arbitrary nearby legacy face. Changes to scatter weighting must be reviewed explicitly because existing deterministic selection maps depend on the pool.
2. **Challenge authority needs a strict reader and explicit adaptation boundary.** `main.js` currently adds one `fc_mult` on any player `entityHitEntity`, resets on player damage/death and decays after inactivity. `P.get` returns untyped raw data; it is not an integer-validation boundary. A canonical use must synchronously reread an available finite integer multiplier >=14 for the same nearby Hero/dimension/source before unlock. Native multiplier scaling, which combat actions qualify, Physical Shield behaviour and original area-transition reduction are not established parity by that check. Do not reuse the deferred legacy form or infer authority from displayed HUD text.
3. **Reward is missing.** `scripts/fc_data.py:LEGENDARIES` and generated item paths contain no Cutlass Bluetane. Add it through the data/resource/behaviour owners with an authored cleaver asset and explicit Minecraft balance; do not substitute the legacy Warrior's Harbinger. The ordinary cleaver item family exists, but that does not mean the Legendary reward currently exists. A fresh room gets one physical shared chest reward, with no opening-time payout.
4. **Destination and return remain full work.** Create a separately owned Butterfly House room with supported routes, chest/return approaches, shell and independent geometry negatives. No exact room dimensions/layout have been verified. Use conservative placement/seed intent plus success receipts, exact native readback and no ambiguous retries as in the completed DP9 offline work. Allocate disjoint storage and retain per-instance history without eviction. Third-family admission, block/explosion/world-generation guards, callback isolation and exact-source ticket returns must be wired into every current two-family helper; both existing families must reject active or unreadable third-family tickets. Lost/replaced ledgers must not revoke each visitor's remembered exit.
